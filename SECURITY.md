# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅        |

## Reporting a Vulnerability

Car Configurator is a client-side only application with no backend, no database, and no external API calls (except Google Fonts).

- No credentials or secrets
- No user data is collected or stored
- No network requests beyond font loading

If you find a security issue, please open a GitHub issue.

## Disclosure

We will acknowledge receipt within 72 hours.
