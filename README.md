# Car Configurator

A 3D car configurator built with vanilla HTML, CSS, and JavaScript. No build step, no framework, no dependencies — just open `index.html` in a browser.

## What it does

- Renders a 3D car scene with CSS transforms and transitions
- Real-time color and material selection
- Smooth entrance animations and ambient effects
- Fully responsive, works on desktop and mobile

## Stack

- HTML5
- CSS3 (CSS variables, transitions, transforms)
- Vanilla JavaScript
- No build tools, no npm packages, no external dependencies (except Google Fonts)

## Usage

```bash
# Just open the file in any modern browser
open index.html
```

Or serve it locally:

```bash
python -m http.server 8000
# then visit http://localhost:8000
```
