# Contributing to Car Configurator

Thanks for your interest! Car Configurator is a 3D car configurator built with vanilla HTML, CSS, and JavaScript. No build step, no framework, no dependencies.

## How to contribute

1. **Fork the repo** and create a branch from `main`.
2. **Make your change** — CSS, JS, or docs.
3. **Open `index.html` in a browser** and verify it works.
4. **Commit with a clear message** — e.g. `feat: add color picker`.
5. **Open a pull request** — describe what changed and why.

## Guidelines

- Keep it dependency-free (no npm packages)
- Test on mobile and desktop
- Use CSS custom properties for theming
